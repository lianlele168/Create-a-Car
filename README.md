# Create a Car Wiki

> 🎮 **Live site:** [https://createacar.robloxwikihub.com](https://createacar.robloxwikihub.com) — interactive calculators, verified code lists, tier lists & guides.

Unofficial Roblox wiki and SEO companion site for Create a Car.

## Pages

- `/` wiki homepage
- `/codes` copyable codes with source-confidence labels
- `/calculator` cash, crate, and upgrade planning tool
- `/tier-list` build archetype tier list
- `/best-build` garage build path
- `/beginner-guide`, `/parts-guide`, `/conveyor-guide`, `/dealer-guide`, `/merge-guide`
- `/updates`, `/about`, `/terms`, `/privacy-policy`

## Data Sources

- Roblox game page and public game API
- Roblox Den, Destructoid, SuperCheats, and UrGameTips code pages
